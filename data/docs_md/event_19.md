                ## Description Complète
                <p>La visite est réalisée par les propriétaires du lieu. Nous expliquons les origines de cette maison et son histoire. Nous mettons en valeur le travail des rocailleurs italiens Gagliardone qui ont réalisé les trois façades. Bien entendu, aprés la visite guidée, les visiteurs peuvent promener librement dans le jardin.</p>
